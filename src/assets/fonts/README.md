# `opencode.otf`

Vendored brand face for the app mark only.

- Source: `~/dev/fonts/opencode/opencode.otf` (also installed in `~/Library/Fonts`), family `OpenCode`, style Regular.
- It is opencode's brand face. No license file accompanied it — flag in report; personal build may bundle it, a future distribution (M5.5) may not.
- Used only for the app mark, scoped under our own family name `OpenCode Mark` (`--oc-font-mark`) so it cannot collide with the system-installed `OpenCode` or leak into the UI.
- The app mark is text in this face; opencode itself renders its wordmark as an SVG, but the user asked for the font.
